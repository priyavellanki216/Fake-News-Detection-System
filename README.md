## Project Overview

The Fake News Detection System is a Machine Learning and NLP-based application that classifies news articles as Real News or Fake News.

The project uses TF-IDF Vectorization and Logistic Regression to analyze news content and predict authenticity.

---

## Features

* Fake News Detection
* Real News Detection
* NLP Text Preprocessing
* TF-IDF Vectorization
* Logistic Regression Classification
* Confidence Score Analysis
* Prediction Probability Chart
* Interactive Streamlit Dashboard
